# Cue legal and support site

Public GitHub Pages site for Cue, developed by Niccolo Felicani.

Use these URLs in Google Play Console:

- Developer website: `https://crackeroni.github.io/cue-legal/`
- Privacy policy: `https://crackeroni.github.io/cue-legal/privacy.html`
- Account deletion: `https://crackeroni.github.io/cue-legal/delete-account.html`

The account-deletion page provides an external request pathway for users who no longer have the app. Cue also provides account deletion inside **Account → Delete account**.
